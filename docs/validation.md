# 验证范围

完整、可追踪的最新结果见仓库的 GitHub Actions。自动测试使用本地模拟器和虚构标识，不需要真实 SIM、飞书应用或测试凭据，也不会发送收费短信。

## 自动验证

- Linux amd64 与 arm64 原生 runner、Windows 和 macOS 执行全部 Go 测试、格式检查与 `go vet`。
- 两种 Linux runner 执行 race，amd64 运行命令解析、号码校验模糊测试。
- 全 Git 历史 Gitleaks、公开文件路径及个人标识检查、可达依赖漏洞扫描。
- 交叉编译五种 64 位系统/架构组合，包含 Linux amd64、arm64。
- 使用统一打包器生成运行包和 SHA256 校验和，实际执行打包后的 Linux amd64 二进制。
- Release 必须完成同一套 CI，才会公开发布包；CI 不访问真实飞书或短信网络。

主要业务测试覆盖：

| 领域 | 验证内容 |
| --- | --- |
| 数据库 | 事务回滚、独占锁、关闭重开恢复 |
| 长短信 | 乱序、重复、重启、模块/SIM/来源隔离、编号复用、冲突、缺片和晚到片 |
| 模块程序 | 执行真实 gateway.lua，模拟 Flash 日志、跨重启 ACK、错误启动号 ACK、溢出、持久化失败、重复发送意图、超时和号码格式 |
| USB 连接 | 分帧、并发请求、断线/超时、物理身份绑定、SIM 变化和取消阻塞写 |
| 机器人 | 用户/群 ACL、事件时效、命令去重、多模块隔离、限额、未知结果不重发、崩溃任务恢复 |
| 飞书 | token 并发缓存、UUID、退避、Unicode 分块和无效响应；官方 SDK 对模拟服务器的 HTTP bootstrap、二进制事件及失败/成功 ACK |
| 业务集成 | 模拟 USB → 事务落盘/组装 → 模拟飞书 HTTP 完整链路，健康接口与退出 |
| 呼转适配 | 默认不支持时不发短信；显式配置后才构造运营商模板 |
| 发布包 | 私有目录/配置不被收录、受控目标及版本、Linux 可执行权限、同输入归档可重复 |

## 硬件验证摘要

在 Air780EPM / V2044_106 / 协议 2 桥接程序上，曾验证：SIM 号码读取、网络注册、短短信提交，以及 190 字中文长短信自身回环，三片组装后真实转发飞书且正文逐字一致。公开仓库不包含这些测试账号、个人号码、会话标识、数据库或原始联调日志。

这项硬件测试使用联通卡；电信卡仍需针对实际 SIM 进行双向验证。只有 Windows 连接过实机；其他平台的 CI 和交叉编译不能代替实际 USB 驱动及运营商联调。

当前模块没有可用的呼转控制 API，也没有彩信载荷下载入口。测试模板或通知降级接口不代表硬件已支持对应功能。有限模块存储、Flash 掉电窗口、短信参考号复用和飞书至少一次投递等边界见 README。
